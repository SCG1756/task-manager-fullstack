# Task Manager Fullstack 🚀

Una aplicación web completa para la gestión de tareas, desarrollada con arquitectura Cliente-Servidor.

## 🛠️ Tecnologías Utilizadas
*   **Backend:** Node.js, Express, MySQL, JWT (JSON Web Tokens), Bcrypt.
*   **Frontend:** Angular 21, TypeScript, Bootstrap.

## ⚙️ Características
*   Autenticación de usuarios (Registro y Login seguro con contraseñas encriptadas).
*   Rutas protegidas con Guards en Angular.
*   CRUD completo de tareas (Crear, Leer, Actualizar y Eliminar).
*   Interfaz responsiva con fondo animado.

## 🚀 Cómo ejecutar el proyecto

### 1. Backend
\`\`\`bash
cd backend
npm install
# Configura tu archivo .env con tus credenciales de MySQL
npm run dev
\`\`\`

### 2. Frontend
\`\`\`bash
cd frontend
npm install
ng serve
\`\`\`
